# Head First Design Patterns – C++ Edition

This repository contains C++ implementations of the examples and exercises from the book *Head First Design Patterns* (originally written in Java).

The goal of this project is to **translate**, **adapt**, and **experiment** with classic design patterns in a modern C++ context — exploring how each pattern fits (or differs) from its Java counterpart.

Each pattern is implemented using idiomatic C++ (RAII, smart pointers, STL, etc.), with an emphasis on clarity and learning rather than production-ready code.

## 💡 Motivation

I started this project as a way to deeply understand design patterns and how they manifest differently in C++.  
Translating Java examples exposes interesting contrasts in memory management, interfaces, inheritance, and object ownership.

## 🧩 Patterns covered so far

- Strategy  
- Observer  
- Decorator  
- Factory Method  
- Abstract Factory  
- Singleton  
- Command  
- Adapter
- Facade  
- Template Method
